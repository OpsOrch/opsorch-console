# OpsOrch Console Agents

This console assumes a single "Console Operator" role:
- Navigates Ops sources through the UI (incidents, logs, metrics, tickets, messaging, services).
- Runs searches/queries, appends timelines, updates tickets, and sends messages without needing provider details.
- Adjusts settings (base URL, health checks) via the admin Settings panel when needed.

If you add automation/AI copilots later, keep their prompts and permissions scoped to this operator role.
